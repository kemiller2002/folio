# AI-discoverable Folio print and report contracts
Date: 2026-11-23. Proposed only.

Every public Folio print component, attribute, page profile, renderer capability, fragmentation behavior and report recipe must expose machine-readable versioned assistant documentation: purpose, constraints, supported P0/P1/P2/P3 tier, accessible reading order, examples, failure/degradation behavior, and compatibility. Enable an authorized AI to explain how to configure tables, running headers, page numbers, notes and document metadata without inventing renderer guarantees.

AI-generated report compositions are drafts only; domain metrics, approvals, immutable issuance and privacy remain with Unbound. Distinguish browser print, controlled PDF and archival/tagged PDF compliance. Do not imply Folio email-client compatibility or Typst interoperability. Use canonical public component manifests and reviewed annotations; generate validation/docs from them and test drift. No implementation claimed.
